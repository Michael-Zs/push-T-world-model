# VAE-JEPA 编码器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在独立分支实现可训练、可评估的空间 VAE-JEPA 世界模型，并与当前 JEPA CEM 控制基线对比。

**Architecture:** VAE encoder 为每个 `8×8` 空间位置产生均值与对数方差，重参数化 latent 同时供动作预测器、pose head 和 VAE decoder 使用。EMA target encoder 产生未来目标 latent；训练联合最小化 JEPA、位姿、重建和 KL warm-up 损失。

**Tech Stack:** Python 3.10、PyTorch、NumPy、Pymunk、PyTest、TensorBoard。

**Spec:** `docs/superpowers/specs/2026-08-27-vae-jepa-design.md`

## Global Constraints

- 保持 CPU 优先、图像尺寸 64、空间 latent 尺寸 `64×8×8`。
- 旧 JEPA checkpoint 必须明确报不兼容，不能静默加载。
- 默认 demo/CEM 接口保持可用；oracle cost 仅作为对照。
- TensorBoard 必须记录 JEPA、重建、KL、推杆位姿、T 位姿损失。
- 评估主指标是固定 5-seed、80-step CEM 的平均最终几何距离。

```python
class VAEImageEncoder(nn.Module):
    def forward(self, image: Tensor) -> tuple[Tensor, Tensor]:
        features = self.backbone(image)
        return self.mean(features), self.logvar(features).clamp(-12, 8)

class VAEJEPAModel(JEPAModel):
    def encode_distribution(self, image: Tensor) -> tuple[Tensor, Tensor]:
        return self.context_encoder(image)
    def sample_latent(self, mean: Tensor, logvar: Tensor) -> Tensor:
        return mean + torch.randn_like(mean) * torch.exp(0.5 * logvar)
    def kl_loss(self, mean: Tensor, logvar: Tensor) -> Tensor:
        return 0.5 * (mean.square() + logvar.exp() - 1.0 - logvar).mean()
```
